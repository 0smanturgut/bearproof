# X drafts

Proof drafts, Osman posts from @bearproofapp. Nothing here is posted automatically.

- `build-<n>.md`: the post for the day Build #n goes live (00:00 UTC). From Build #3 on, the Build Agent writes
  these itself in the same pull request as the build.
- `0NN-*.md`: one-off posts (entry, coin launch, milestones), numbered in posting order.

Format: a note for Osman (when to post, what to attach), then `---`, then the post (≤ 280 characters), then
optional `---` replies. Language rules are in `docs/LAUNCH.md`: builds, players, receipts. Never price.
