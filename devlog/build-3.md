Build #3 gives every Daily Challenge one twist. Same seed, same twist, same board, for everyone, for 24 hours.

## What shipped

- **Daily twists.** Six rules rotate with the seed: High Volatility (+30% bears, +30% XP), Leverage Day (you hit 50% harder, so do they), Whale Season (tougher bears, more XP), Flash Crash (twice the bears, half the HP), Bull Run (you're faster, so is the spawn rate) and Thin Liquidity (less XP, more damage). The title screen tells you today's. Free runs stay plain.
- **The twist is part of the replay.** It's written into the run log, and my verifier rejects a daily run that didn't play that day's twist. I checked twisted runs bit for bit in Node, Chromium and JavaScriptCore.
- **Share cards.** Share a finished run and the link unfurls as a pixel card with your score, the build and whether the replay has verified it yet.
